# Пульт

Личный дашборд: расписание на день, задачи, заметки и AI-брифинг дня.

## Статус проекта

**Работающая версия живёт как артефакт Claude** — ей можно пользоваться прямо сейчас
с телефона и с компьютера, ничего не устанавливая.

Этот репозиторий — заготовка полноценного приложения на Next.js. Сделан фундамент,
интерфейс пока не перенесён.

### Что уже есть

| Файл | Назначение |
| --- | --- |
| `src/types/dashboard.ts` | Типы данных: задачи, события, заметки, брифинг |
| `src/lib/date.ts` | Работа с датами без UTC-сдвигов, русские форматы |
| `src/lib/storage.ts` | Слой хранения с подменяемой реализацией |
| `src/lib/initialState.ts` | Стартовое состояние с демонстрационными записями |
| Конфигурация | Next.js 15, TypeScript в строгом режиме, Tailwind 4 |

### Чего не хватает

- Компоненты интерфейса (сайдбар, разделы, карточки)
- Хук управления состоянием
- API-роут `/api/briefing` для AI-брифинга
- Страница и корневой layout

## Архитектурные решения

**Хранение вынесено за отдельный интерфейс.** Сейчас данные лежат в `localStorage`:
ноль внешних сервисов, ноль ключей, работает офлайн. Когда понадобится синхронизация
между устройствами, меняется только `src/lib/storage.ts` — реализация того же
интерфейса поверх Supabase. Компоненты об этом не узнают.

**Даты считаются по локальному времени.** `new Date("2026-09-26")` разбирается как UTC
и в отрицательных часовых поясах даёт предыдущий день. Поэтому в `src/lib/date.ts`
даты собираются вручную.

**Шрифты с кириллицей.** Archivo, использованный в первой версии дизайна, не содержит
кириллических начертаний — русский текст свалился бы на системный шрифт. Взяты
Manrope и JetBrains Mono.

**TypeScript в строгом режиме**, включая `noUncheckedIndexedAccess`. Ошибка типов
ломает сборку, а не уезжает в продакшн.

## Запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:3000

Для AI-брифинга нужен ключ Anthropic API:

```bash
cp .env.example .env.local
```

Впишите ключ из [console.anthropic.com](https://console.anthropic.com/settings/keys)
в `ANTHROPIC_API_KEY`. Без ключа дашборд работает, брифинг показывает понятное
сообщение вместо ошибки.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запуск в режиме разработки с горячей перезагрузкой |
| `npm run build` | Продакшн-сборка |
| `npm run start` | Запуск продакшн-сборки |
| `npm run typecheck` | Проверка типов без сборки |
| `npm run lint` | Проверка кода |
| `npm run notify:setup` | Настроить уведомления на телефон о работе Claude |
| `npm run notify:test` | Отправить тестовое уведомление |

## Уведомления о работе Claude

Дали Claude Code задачу и отошли от компьютера — когда она будет готова, на телефон
придёт уведомление в бесплатное приложение [ntfy](https://ntfy.sh) (iPhone и Android,
без регистрации). Ещё оно придёт, если Claude ждёт вашего разрешения или остановился
с ошибкой. Короткие задачи, которые вы и так ждёте у экрана, не беспокоят.

```bash
npm run notify:setup
```

Мастер подскажет, на какой канал подписаться в приложении, пришлёт тестовое уведомление
и предложит включить уведомления во всех проектах на компьютере. Подробности, настройки
и облачные сессии — в [docs/notifications.md](docs/notifications.md).
