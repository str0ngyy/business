# Шкала усталости Claude

Цветная шкала: насколько Claude «устал» в текущем чате и когда пора открыть новый,
где он снова свежий.

## Что на самом деле измеряется

Claude не устаёт буквально. «Усталость» — это заполненность контекстного окна:
чем длиннее чат, тем больше информации Claude держит в голове одновременно, тем
хуже он вспоминает ранние детали, а у границы окна срабатывает автосжатие —
старая часть переписки пересказывается кратко и детали теряются.

| Зона | Усталость | Что делать |
| --- | --- | --- |
| 🟢 Свежий | 0–39% | Полная концентрация — самое время для сложных задач |
| 🟡 Бодрый | 40–59% | Всё хорошо; новую большую задачу лучше начать в новом чате |
| 🟠 Устаю | 60–79% | Доделай текущую задачу и переходи в новый чат |
| 🔴 Пора в новый чат | 80–100% | Скоро автосжатие — открой новый чат |

- Процент считается от окна модели, но не больше 400k токенов: у моделей с окном
  1M качество проседает задолго до его конца, и шкала это учитывает.
- После сжатия контекста шкала не опускается ниже 🟠, даже если токенов стало мало:
  ранние детали уже пересказаны кратко.

## Где видно

Шкала стоит прямо над полем ввода, там, где пишешь запрос:

```
🟡 Бодрый  ██████████░░░░░░░░░░  45%  · 180k / 400k токенов
Усталость Claude · Всё хорошо. Новую большую задачу лучше начать в новом чате.
```

Это работает в **сессиях на своём компьютере**: в терминале Claude Code и во
вкладке Code десктоп-приложения Claude, если сессия локальная. Там же — уведомление
при переходе в следующую зону и строка статуса с зоны 🟠.

**Облачные сессии** (claude.ai/code и облачный режим приложения) показывают
только текст переписки: моды не могут рисовать у поля ввода. Проверено: полоса,
уведомления, строка статуса и подсказка в поле ввода до приложения не доходят.
Там доступна только команда `/fatigue`.

**Команда `/fatigue`** выводит полный отчёт со шкалой и легендой — везде.

## Подключение

### Свой компьютер — все проекты

1. Слить ветку с модом в основную: маркетплейс читается из основной ветки.
2. В терминале запустить `claude` и выполнить:

   ```
   /plugin install fatigue-meter --marketplace str0ngyy/business
   ```

   На вопрос о маркетплейсе ответить `y`, область — user.

После этого шкала появляется в каждой локальной сессии: в терминале и в
десктоп-приложении.

### Облачные чаты этого репозитория (только `/fatigue`)

Облачная сессия не загружает моды из `.claude/skills` проекта, поэтому мод
подключается переменной окружения в настройках облачного окружения:

```
CLAUDE_CODE_PLUGIN_DIRS=/home/user/business/.claude/skills
```

## Разработка

```
claude plugin validate .claude/skills/fatigue-meter
claude plugin test .claude/skills/fatigue-meter
```
