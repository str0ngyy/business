# Уведомления на телефон о работе Claude

Вы даёте Claude Code задачу и уходите от компьютера. Когда задача готова, на телефон
приходит сообщение: можно возвращаться и давать следующее задание.

| Что случилось | Что придёт | Когда |
| --- | --- | --- |
| Задача выполнена | ✅ **Готово · muscly**<br>Заняло 7 мин 12 с<br>Краткий пересказ ответа | Задача шла дольше порога (по умолчанию 60 с) |
| Нужно ваше решение | ✋ **Нужно решение · muscly**<br>Claude просит разрешение: Bash | Посреди длинной задачи Claude ждёт разрешения или ответа |
| Ошибка | ❌ **Остановился с ошибкой · muscly**<br>Упёрся в лимит использования | Лимит, сбой API — работа встала |

Уведомления приходят в бесплатное приложение [ntfy](https://ntfy.sh) для iPhone и Android:
без регистрации, без номера телефона, без аккаунта. По желанию можно добавить Telegram-бота.

## Настройка

Нужен Node.js 18+ — он уже стоит, раз вы работаете с Next.js.

```bash
npm run notify:setup
```

Мастер проведёт по шагам:

1. **Канал.** Нажмите Enter — выберется ntfy.
2. **Приложение.** Поставьте ntfy ([iPhone](https://apps.apple.com/app/ntfy/id1625396347),
   [Android](https://play.google.com/store/apps/details?id=io.heckel.ntfy)), разрешите ему
   уведомления, нажмите «+» и впишите имя канала, которое покажет мастер
   (вида `claude-3f9a…`). Сервер оставьте по умолчанию.
   Если выбрали Telegram: в @BotFather отправьте `/newbot`, вставьте токен в мастер и
   напишите боту любое сообщение — chat_id мастер найдёт сам.
3. **Порог.** С какой длительности задачи присылать уведомления.
4. **Тест.** На телефон сразу придёт проверочное сообщение.
5. **Все проекты.** Мастер предложит включить уведомления глобально — для Muscly и любых
   будущих проектов на этом компьютере, не только для этого репозитория.

Уже открытые сессии Claude Code подхватят хуки после перезапуска или после того, как
вы откроете в них `/hooks`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run notify:setup` | Мастер настройки; повторный запуск меняет настройки |
| `npm run notify:test` | Отправить тестовое уведомление |
| `node .claude/hooks/notify-setup.mjs --status` | Показать настройки и последние записи журнала |
| `node .claude/hooks/notify-setup.mjs --install` | Включить во всех проектах без вопросов |
| `node .claude/hooks/notify-setup.mjs --uninstall` | Выключить во всех проектах |

## Как это устроено

Всё построено на [хуках Claude Code](https://code.claude.com/docs/en/hooks) — командах,
которые Claude Code сам запускает на событиях сессии. Решение об отправке принимает
скрипт, а не модель, поэтому уведомление приходит всегда, а не «когда Claude вспомнит».

| Событие хука | Что делает скрипт |
| --- | --- |
| `UserPromptSubmit` | Запоминает время начала задачи. Ничего не отправляет |
| `Stop` | Claude закончил ответ → «Готово», если задача шла дольше порога |
| `Notification` | Запрос разрешения или вопрос → «Нужно решение» |
| `StopFailure` | Ответ оборвался из-за ошибки API → «Остановился с ошибкой» |

**Без спама.** Короткие задачи вы обычно ждёте у компьютера — о них не пишу. «Готово»
приходит один раз за задачу. Напоминание «Claude ждёт ввода» после «Готово» не
дублируется. Если хук стоит и глобально, и в проекте, уходит одно уведомление, а не два.

**Не мешает работе.** Отправка идёт в фоне: Claude не ждёт ответа сети. Любой сбой
(нет интернета, неверный токен) пишется в журнал, а хук всё равно завершается успешно.

**Без зависимостей.** Один файл на чистом Node.js. За прокси (корпоративная сеть,
облачная сессия) отправляет через `curl`, который прокси учитывает.

## Настройки

Мастер пишет их в `~/.claude/notify.env`. Переменные окружения с теми же именами важнее
файла.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `CLAUDE_NOTIFY_NTFY_TOPIC` | — | Канал ntfy. Работает как пароль |
| `CLAUDE_NOTIFY_NTFY_SERVER` | `https://ntfy.sh` | Свой сервер ntfy |
| `CLAUDE_NOTIFY_NTFY_TOKEN` | — | Токен доступа для своего сервера ntfy |
| `CLAUDE_NOTIFY_TELEGRAM_TOKEN` | — | Токен бота от @BotFather, если нужен Telegram |
| `CLAUDE_NOTIFY_TELEGRAM_CHAT_ID` | — | Куда слать в Telegram; мастер находит сам |
| `CLAUDE_NOTIFY_TELEGRAM_API` | `https://api.telegram.org` | Зеркало Bot API, если основной адрес недоступен |
| `CLAUDE_NOTIFY_MIN_SECONDS` | `60` | Порог длительности задачи; `0` — присылать всегда |
| `CLAUDE_NOTIFY_INCLUDE_SUMMARY` | `1` | `0` — не включать пересказ ответа в уведомление |
| `CLAUDE_NOTIFY_DISABLED` | `0` | `1` — временно выключить всё |
| `CLAUDE_NOTIFY_DEBUG` | `0` | `1` — объяснять в журнале каждое решение «слать / не слать» |

## Облачные сессии (claude.ai/code)

Хуки из `.claude/settings.json` срабатывают и в облаке, но там нет вашего
`~/.claude/notify.env`, а сетевая политика по умолчанию не пускает к ntfy и Telegram.
Чтобы уведомления приходили и оттуда:

1. В настройках облачного окружения (меню окружения в заголовке сессии → **Edit**)
   задайте переменную `CLAUDE_NOTIFY_NTFY_TOPIC` — тот же канал, что в приложении
   (для Telegram — `CLAUDE_NOTIFY_TELEGRAM_TOKEN` и `CLAUDE_NOTIFY_TELEGRAM_CHAT_ID`).
2. В **Network access** добавьте `ntfy.sh` (для Telegram — `api.telegram.org`) в
   **Allowed domains**, оставив галочку для менеджеров пакетов.
   [Документация](https://code.claude.com/docs/en/cloud-environments#network-access).

В уведомлении из облака будет кнопка «Открыть сессию».

## Ответить прямо с телефона

Уведомление говорит, что пора вернуться. Можно и не возвращаться: если запустить сессию
через Remote Control (`claude remote-control` в папке проекта), она появится в приложении
Claude на телефоне, и следующее задание можно дать оттуда.

## Если уведомление не пришло

1. `npm run notify:test` — доходит ли тестовое. Если нет, причина в журнале
   `~/.claude/notify-state/notify.log`.
2. Задача могла быть короче порога. Для проверки поставьте `CLAUDE_NOTIFY_MIN_SECONDS=0`.
3. Сессия была открыта до установки — перезапустите её или откройте `/hooks`.
4. На iPhone проверьте, что уведомления для ntfy разрешены: Настройки → Уведомления → ntfy.
5. `CLAUDE_NOTIFY_DEBUG=1` — журнал покажет, почему конкретное событие пропущено.

## Безопасность

- ntfy.sh — публичный сервер: кто знает имя канала, тот читает уведомления. Поэтому мастер
  генерирует случайное имя на 64 бита — подобрать его невозможно, главное никому его не
  показывать. Если не хотите, чтобы пересказ ответов уходил на чужой сервер, выключите его
  (`CLAUDE_NOTIFY_INCLUDE_SUMMARY=0`) или поднимите свой сервер ntfy.
- Имя канала и токены лежат в `~/.claude/notify.env` с правами `600`, вне репозитория.
  В `curl` они передаются через временный файл, а не аргументом командной строки:
  аргументы процессов видны другим пользователям системы.
- Глобальная установка меняет только свои записи в `~/.claude/settings.json` и перед
  каждой записью сохраняет копию `settings.json.backup-<время>`. Невалидный файл мастер
  не трогает.
